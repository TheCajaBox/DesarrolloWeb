# El Sombrero de Wayne

Un taller para aprender a construir una web de verdad, desde cero, con Vue.

No hace falta instalar nada más: ni Node, ni un editor, ni cuenta de nada.
Tampoco necesita internet.

## Instalar (Windows)

1. Doble clic en **`El Sombrero de Wayne Setup.exe`**.

2. Windows va a avisar de que no reconoce la aplicación. Es normal: el
   instalador no está firmado con un certificado de pago. Para continuar:
   **Más información → Ejecutar de todas formas**.

3. Se instala solo, sin preguntar nada, y se abre. También queda en el menú
   de inicio como *El Sombrero de Wayne*.

Se instala para tu usuario, así que no pide permisos de administrador.

## Cómo funciona

La ventana tiene tres columnas, y **se pueden ensanchar arrastrando las
líneas** que las separan:

- **Izquierda**: la lección. Wax explica, y debajo está el ejercicio con su
  botón de *Comprobar*. Hay pestañas para los ficheros del proyecto y para
  preguntarle a Armonía.
- **Centro**: el editor. Es el mismo de VS Code, con autocompletado: prueba a
  escribir `v-` dentro de una etiqueta, o `ref` en el script.
- **Derecha**: el resultado. Lo que estás construyendo, en vivo: guarda y se
  actualiza. En los mundos de base de datos, ahí está la consola de SQL.

Wayne está abajo a la derecha comentando. Si molesta, pulsa su retrato y se
calla (sigue ahí).

## Cosas que conviene saber

- **Se guarda solo.** No hay que darle a guardar nada, ni al cerrar.
- **El proyecto es tuyo.** Los mundos crean los ficheros que necesitan, pero
  nunca pisan lo que tú hayas escrito. Puedes crear ficheros propios y no los
  toca nadie.
- **El progreso se recuerda**, aunque cierres la aplicación.
- **Los mundos se abren en orden**: cada uno se desbloquea al terminar el
  anterior. Si prefieres cotillear el temario entero, el botón *Por orden* de
  arriba los abre todos.
- **Si te atascas**: cada ejercicio tiene *Dame una pista*, y no es hacer
  trampa. Armonía (la pestaña de la izquierda) responde dudas y explica
  palabras, pero no da la solución. Y las palabras raras están en el
  *Glosario*, arriba.
- **Reiniciar mundo** deja ese mundo como estaba al empezarlo, si algo se ha
  liado mucho.
- **Exportar mi web** (arriba a la derecha) compila lo que has hecho y abre la
  carpeta con la web ya montada, lista para subir a cualquier sitio.

## El temario

Diez actos, treinta y seis mundos. Se empieza cambiando una palabra en un
título y se acaba con pruebas automáticas y una base de datos indexada:

1. **Un componente** — qué es un `.vue` y cómo se escribe HTML de verdad
2. **Que se vea** — CSS, cajas, flexbox y rejillas que se adaptan
3. **Datos** — que la página piense: `ref`, listas, buscadores, formularios
4. **Componentes que hablan** — partir la app en piezas: props, eventos, slots
5. **Varias pantallas** — el router y una dirección para cada cosa
6. **Estado compartido** — Pinia, y una cesta que sobrevive a la recarga
7. **El servidor** — pedir datos, tratar los errores y no dejar agujeros
8. **Publicar** — que la web sepa presentarse
9. **La base de datos** — SQL de verdad, sobre una base de datos de verdad
10. **Compilar y preparar** — el proyecto por dentro, y pruebas automáticas

Y al final, un examen: seis encargos sin pistas.

---

Si algo se rompe o se queda en blanco, cierra y vuelve a abrir: el progreso y
los ficheros están a salvo. Y si sigue roto, dilo, que se arregla.
